🪨📄✂️ Rock Paper Scissors Game

A simple and interactive **Rock Paper Scissors** game built using **HTML, CSS, and JavaScript**. Play against the computer with a clean UI and emoji-based visuals.

---

🚀 Features
- Play Rock, Paper, or Scissors against the computer
- Random computer choices
- Instant result display (Win / Lose / Tie)
- Simple and responsive design
- Emoji-based game assets

---

🛠️ Tech Stack
- HTML
- CSS
- JavaScript

---

▶️ How to Run the Project
1. Clone or download the repository
2. Open `RockPaper.html` in any web browser
3. Start playing 🎮
